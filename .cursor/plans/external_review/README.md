# External Review Directory

This directory contains external reviews of the AgVFM2 research approach, methodology, and manuscript.

## Review System

### Review Index

See [review_index.md](review_index.md) for a complete list of all reviews, their status, and response tracking.

### Review Format

Each review follows this structure:
- **Review ID:** Unique identifier (review_XXX)
- **Date:** Review date
- **Reviewer:** Reviewer name/role
- **Focus Area:** What the review covers
- **Status:** Complete, In Progress, Pending Response

### Review Content

Reviews include:
1. **Executive Summary:** Overall assessment and recommendation
2. **Strengths:** What the work does well
3. **Major Concerns:** Critical issues to address
4. **Technical Comments:** Detailed feedback on methodology
5. **Manuscript Quality:** Writing, structure, figures
6. **Specific Recommendations:** Actionable items prioritized
7. **Minor Issues:** Small fixes and improvements

## How to Use Reviews

1. **Read the review:** Start with the Executive Summary for overall assessment
2. **Prioritize feedback:** Address "Must fix" items first, then "Should improve"
3. **Track responses:** Update the review index with response dates and files
4. **Iterate:** Reviews can be updated as work progresses

## Adding New Reviews

When adding a new review:

1. **Assign Review ID:** Use next sequential number (review_002, review_003, etc.)
2. **Create Review File:** `review_XXX_YYYYMMDD.md` (e.g., `review_002_20250220.md`)
3. **Update Index:** Add entry to [review_index.md](review_index.md)
4. **Follow Format:** Use review_001 as a template

## Response Tracking

When responding to a review:

1. **Create Response File:** `response_review_XXX_YYYYMMDD.md`
2. **Update Index:** Mark review as "Responded" in [review_index.md](review_index.md)
3. **Address Items:** Systematically address each recommendation
4. **Document Changes:** Note which changes were made and which were deferred

## Review Guidelines

For future reviewers:

- **Be constructive:** Focus on improving the work, not just critiquing
- **Be specific:** Provide concrete examples and actionable recommendations
- **Be balanced:** Acknowledge strengths as well as weaknesses
- **Be prioritized:** Clearly distinguish must-fix from nice-to-have
- **Be respectful:** Maintain professional tone throughout
