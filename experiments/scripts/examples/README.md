# Example Scripts

Example scripts demonstrating how to use the `agvfm` package.

## Scripts

### `example_usage.py`

Demonstrates basic usage of the `agvfm` package:
- Loading models
- Running predictions
- Evaluating prompts
- Computing metrics

**Usage:**
```bash
python experiments/scripts/examples/example_usage.py
```

## Learning the Package

This script shows:
1. How to load YOLO World and SAM3 models
2. How to run predictions on images
3. How to use the Evaluator class
4. How to compute metrics

Use this as a starting point for your own scripts!
